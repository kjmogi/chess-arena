# 체스 아레나

우리 반 체스 랭크 리그 웹앱입니다. 두 가지 모드로 동작해요.

| 모드 | 언제 | 데이터 위치 | 대전 |
|---|---|---|---|
| **데모 모드** | `js/config.js` 가 비어 있을 때 (기본) | 이 브라우저 localStorage | 같은 브라우저의 탭끼리 |
| **온라인 모드** | `js/config.js` 에 Supabase 정보를 넣었을 때 | Supabase 서버 | 학생마다 다른 기기에서 |

## 데모 모드로 실행

정적 파일이라 아무 웹 서버로 열면 됩니다.

```bash
npx -y http-server@14.1.1 . -p 8765 -c-1
```

http://localhost:8765 접속 → 반 코드 `demo`, 비밀번호 `1234`
- 선생님: `teacher`
- 학생: `kim01` `lee02` `park03` `choi04` `jung05` `kang06` `yoon07` `han08`

같은 브라우저에서 탭을 여러 개 열어 서로 다른 학생으로 로그인하면 실시간 대전이 됩니다(탭마다 로그인이 따로 유지됨).

## 온라인 모드 (Supabase) 설정

한 번만 하면 됩니다. 10분 정도 걸려요.

1. **프로젝트 만들기** — https://supabase.com 에 가입하고 *New project*.
   - Region은 **Northeast Asia (Seoul)** 을 고르면 가장 빠릅니다.
   - 데이터베이스 비밀번호는 아무거나 정해도 됩니다(이 앱에서는 쓰지 않음).
2. **표와 함수 만들기** — 왼쪽 메뉴 *SQL Editor* → *New query* 에 [`supabase/setup.sql`](supabase/setup.sql) 내용을 통째로 붙여 넣고 **Run**.
   `Success. No rows returned` 가 나오면 끝입니다. 여러 번 실행해도 기존 데이터는 지워지지 않아요.
3. **키 복사** — *Project Settings* → *API Keys* (또는 *Data API*) 에서
   - **Project URL** (예: `https://abcdefgh.supabase.co`)
   - **Publishable key** (`sb_publishable_…`) 또는 **anon public** 키
4. **`js/config.js` 에 붙여 넣기**
   ```js
   window.CHESS_ARENA_CONFIG = {
     supabaseUrl: 'https://abcdefgh.supabase.co',
     supabaseKey: 'sb_publishable_...'
   };
   ```
   ⚠️ `service_role` / `secret` 키는 절대 넣지 마세요. 이 파일은 학생 브라우저에 그대로 전달됩니다.
5. **올리기** — 폴더 전체를 GitHub Pages, Netlify, Vercel 등 정적 호스팅에 올리고, 그 주소를 학생들에게 알려 주세요.
6. 접속해서 **「새 반 만들기 (선생님)」** 로 반을 만들고, 「학생 관리」에서 학생을 일괄 등록하면 됩니다.

### 온라인 모드에서 알아 둘 점
- **무료 플랜 일시정지**: Supabase 무료 프로젝트는 1주일 동안 아무도 쓰지 않으면 일시정지돼요. 방학 뒤 처음 쓸 때 대시보드에서 *Restore project* 를 눌러 주세요(데이터는 그대로).
- **비밀번호**: 서버에 해시로 따로 저장되어 브라우저에서 읽을 수 없어요. 학생 비밀번호 변경은 선생님 계정만 할 수 있어요.
- **보안 수준**: 교실용으로 간단하게 만든 구조입니다. 반 코드를 아는 사람은 경기 기록·순위를 볼 수 있고, 로그인한 학생이 개발자 도구를 다루면 점수 같은 기록을 고칠 수도 있어요. 실제로 쓰는 다른 비밀번호를 학생 비밀번호로 쓰지 않게 해 주세요.
- **동시에 누를 때**: 두 사람이 같은 경기·대기열을 동시에 바꾸면 서버가 한쪽을 되돌려 보내고, 브라우저가 최신 내용으로 다시 처리해요(경기가 두 번 생기거나 점수가 두 번 반영되지 않음).
- **시계**: 제한 시간은 서버 시각 기준이라 기기 시계가 달라도 똑같이 흘러요.
- **학교 방화벽**: 실시간 연결(WebSocket)이 막히면 4초마다 새로 불러오는 방식으로 자동 전환돼요. 다만 이때는 접속 표시가 보이지 않아요.
- 온라인 모드에는 데모 계정이나 데모 초기화 버튼이 없어요.

## 구성
| 파일 | 내용 |
|---|---|
| `js/config.js` | Supabase 연결 정보 (비워 두면 데모 모드) |
| `supabase/setup.sql` | Supabase 표·권한·함수 만들기 |
| `js/chess.js` | 체스 규칙 엔진 (합법 수, 캐슬링, 앙파상, 승진, 체크메이트·스테일메이트·기물 부족·50수·3회 반복, SAN 기보) |
| `js/ai.js` | 연습용 AI (입문/중급/상급, 알파-베타 탐색) |
| `js/store.js` | 저장소 — 데모(localStorage + 탭 간 동기화) / 온라인(Supabase 실시간 동기화, 동시 수정 처리, 접속 표시) |
| `js/rating.js` | 랭크 점수(Elo 방식), 배치고사 5경기, 티어, 하루 경기 수 제한, 무효 처리 |
| `js/ui.js` | 체스판, 티어 엠블럼, 모달, 기보 다시 보기, 승급 연출 |
| `js/app.js` | 로그인, 학생 홈(랜덤 매치·1:1 도전·AI 연습), 대국 화면 |
| `js/admin.js` | 선생님 화면(실시간 경기, 매치 배정, 학생 관리, 순위표, 경기 기록, 설정) |
